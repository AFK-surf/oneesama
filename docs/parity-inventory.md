## Required Replacement Modules

- [ ] `SlackAppAdapter`: real Slack Socket Mode / Events API integration.
- [x] `PersistentSessionStore`: memory/json-file/sqlite adapter for sessions and jobs.
- [ ] `MeetRuntime`: non-dry-run Playwright launcher with lifecycle guard.
- [ ] `DialogProviderBridge`: provider-selected speech/text loop. Current slice has a Realtime browser bridge for WebRTC/data channel, mock event creation, a `webrtc-mock` data-channel seam, session.update registration for instructions/tools, participant-audio discovery, mock remote-audio route into the avatar fake mic bus, duplicate worker-result suppression, user-speech response cancellation, worker tool handling, avatar mood/action tool handling, integrated runtime acceptance smoke, optional real-SDP smoke, and optional real Realtime live-tool smoke for `delegate_to_worker`.
- [ ] `AvatarRuntimeBridge`: Hiyori render/mouth/expression/action state. Current slice includes CI-safe visual hash/diff gates for local mouth/action changes plus an optional true Hiyori Live2D pixel gate.
- [ ] `AudioBridge`: Meet participant audio -> Realtime input; model audio -> fake mic output.
- [ ] `WorkspaceToolAdapter`: public interface for Linear/Slack/Calendar/etc., with private implementations outside the public repo.
- [x] `AgentRunnerProvider`: public interface for bring-your-own local/remote agent runners (`dry-run`, `codex`, `claude`, `ollama`, `slack-agent-d`, `command`, `http`).
- [x] `DelegateReporter`: first worker status/result fanout to Slack and Meeting/Realtime in local smoke, including mock Slack thread posting.
- [ ] `Diagnostics`: screenshots, structured JSONL logs, and health/status APIs.

## Cutover Blockers

- [x] New repo can join a local Meet fixture without dry-run and has an optional real Google Meet room smoke for live evidence capture.
- [x] New repo can speak a selected provider response through the local dialog TTS/fake-mic seam in fixture smoke.
- [ ] New repo cannot yet listen to real participant speech through a production STT provider.
- [ ] New repo has no real Slack OAuth/Socket Mode adapter and no live Slack token acceptance for result posting yet.
- [x] New repo has a replaceable `memory` / `json-file` / `sqlite` state provider seam and restart smokes; production backup/retention policy is not selected yet.
- [ ] New repo has local avatar emotion/action runtime state and optional true Live2D pixel smoke, but no real-session acceptance or sidecar classifier yet.
- [ ] New repo has a local worker delegation bridge and Slack-side result polling/posting seam, but no private workspace tool adapter boundary beyond that bridge.
- [ ] New repo can record shadow/canary/rollback decisions, execute fixture-level old-vs-new parity comparison, receive old-stack mirrored commands through a safe shadow tap, and smoke-test the sanitized transmitter hook, but does not yet wire that hook into old Slack Agent D or execute a full live old-stack comparison.

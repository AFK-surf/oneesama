# Code of Conduct

## Our Standard

We want `oneesama` to feel welcoming, practical, and respectful.

Examples of expected behavior:

- be kind and constructive
- assume good intent, but be clear when something is risky or incorrect
- give technical feedback about the work, not the person
- share context that helps others reproduce, review, and learn

Examples of unacceptable behavior:

- harassment, discrimination, or intimidation
- personal attacks or bad-faith pile-ons
- publishing someone else's private data, credentials, or meeting content
- deliberately disruptive behavior in issues, discussions, or pull requests

## Scope

This applies in repository discussions, issues, pull requests, and other project spaces.

## Enforcement

Project maintainers may remove, edit, or reject contributions and discussions that violate this code of conduct.

## Reporting

For conduct concerns or safety issues, contact the maintainers privately rather than escalating in public threads.

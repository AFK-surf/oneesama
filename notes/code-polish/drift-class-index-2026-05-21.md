## Index maintenance rules

- Promote a "Observed but not yet promoted" candidate to "Promoted first-class" only when a second worked example commit lands; until then, keep it in the observed section.
- When a new commit closes an instance of a class, append it to the anchor-commit cell rather than overwriting.
- When a class is renamed, update the long doc heading and this index in the same commit; do not silently drop the old name.
- Keep one-line definitions actually one line. The long doc has room for prose; this index does not.

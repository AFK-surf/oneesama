一眼结论

现在不应该新增一个 kwwk_control_shared_app_window。更合理的形状是： 保留兼容的 control_shared_app_window tool 名，但用 executionMode 明确分流。
  • 简单操作：executionMode: "direct"，走 KWWK/direct backend。Realtime 只给 自然语言 instruction，由 KWWK 负责 observe → plan → act → verify。
  • 复杂任务：executionMode: "delegate"，启动 Codex app-control worker。 适合需要视觉探索、多步规划、不熟 UI、验证闭环的任务。
  • 浏览器/生成工作不应该塞进 app-control：URL、网页、生成结果展示走 browser/demo surface 这一组 tool。
风险点： control_shared_app_window 的名字仍然比较泛，模型需要靠 description 和 executionMode 判断快慢路径。后续如果要彻底清爽， 可以做一次 schema migration，把 direct app 操作和 delegate app 操作拆成两个 更窄的 foreground tools。

Sidecar 限制

  • Meet surface role 只允许本地执行 Meet DOM 相关工具。
  • Sidecar page 对 send_meet_chat / read_meet_chat 只能通过 host surface port 转发给 surface；port 缺失时 fail closed。
  • app-control 和 worker 类工具应该留在 sidecar/local service 路径，不在 Meet DOM 页面里直接做。
  • demo/browser surface tools 即使被 raw local-tool path 调用，也只有在 demoSurface.toolsExposed 明确开启时才会转发；demoSurface.enabled 只表示 backend bridge 存在，不再等同于 foreground tool 暴露；浏览器 local router 和 Go /tools 只接受当前 schema 名；旧 backend 名 start_demo_surface/start_demo_execution/control_demo_surface/cancel_demo_surface 现在即使 exposed 也返回 deprecated_demo_surface_tool。
  • Meet surface placeholder 现在只保留 DOM tool / audio forwarding 需要的配置；不再携带 sidecar SDK-owned tools、session、instructions、 OpenAI endpoint 字段、worker URL 或 current-user context，避免 meet.google.com 页面残留前台 schema / prompt state。
  • worker-result 不能由生产页 DOM custom event 伪造；直接注入也必须带当前 meeting session id；host 注入找不到 Realtime client API 时不再退回 custom event；poll-based delivery 还必须带服务端发出的 realtime delivery token 才能标记 delivered；session-missing / session-mismatch / no-action suppress 现在只写 realtimeSuppressed，不能再污染 deliveredToRealtime。
  • host_meet_audio_pcm 是合法 fixture/diagnostic sidecar input source；真实 Google Meet live gate 只把 recappi_process_audio_tap 视为可验证的 Realtime sender，避免诊断源冒充 Recappi live path。

建议改进

  • Benchmark 要分别测 direct KWWK、delegate Codex、browser surface 三条路径。
  • HUD 不显示 speaking / 连接中 / 没音频 这类低价值等待态；只显示工具队列、 running、done、blocked。HUD playground 的视觉回归现在会先等 听语音 cell 和实际 canvas 像素出现，再截快照，避免状态切换后一帧内误报空 HUD。
  • queued app-control worker report 先写 evidence event，再暴露 terminal job status；这样 benchmark/status poll 不会先看到 completed 却还拿不到 worker report。
  • direct KWWK 要继续测 instruction-only 路径，确保 Realtime 不需要生成坐标或 click/type/drag primitives；live-routing smoke 里旧的 requireOperations 分支已删除，只保留 instruction 与 forbid-operations 检查；Swift KWWK helper 也不再读取 top-level operations params；Go app-control endpoint 已拒绝隐藏 standalone flag，并移除旧 synthetic standalone 分支。
  • 生产态 Meet surface 不接受页面任意 meeting-avatar-participant-audio-stream custom event 作为 Realtime 输入证据；直接 participant-audio discovery/registration 也不是 MAB_REALTIME_CLIENT public API，fixture/mock 只通过内部 discovery / custom event opt-in 路径覆盖。
  • Go host /realtime/client-secret 已对 transient EOF / 5xx 加 bounded retry；本次 npm run benchmark:realtime-tool-recall -- --case-filter '^control_' 在临时 live-wrapper Go meeting-agent 上通过 full 4/4 和 share-control-only 4/4。
  • Go host config 只接受 openai.realtime_runtime_placement=sidecar；inline 只保留在非 Meet 的低层 browser diagnostic。
  • Go host config 会拒绝 demo_surface.expose_realtime_tools=true 搭配 default/fake demo-surface adapter；暴露给 Realtime 的 browser/CU surface 必须使用 mode=safe、adapter=agent_browser 或 adapter=codex。
